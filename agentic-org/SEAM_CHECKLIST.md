## Consolidated Findings

- CF-01 P1 CONFIRMED: A raw-only private branch tip can be accepted for current agent mounts when older structurally valid desk indexes already exist. Consequence: Reporters can pitch from stale mounted research while Git shows a newer archived capture.
- CF-02 P1 CONFIRMED: record_assignment does not require exactly one forecast slot and does not require that forecast slot to name a different-desk dissenter. Consequence: The forecast gate may never activate, or may activate without an addressed dissent handoff.
- CF-03 P1 CONFIRMED: file_desk / deskDocumentFindings do not require or validate World Desk trace provenance. Consequence: Ledger can file a World Desk number without proving continuity to the private trace required by the brief.
- CF-04 P2 CONFIRMED_PUBLICATION_POLICY_GAP: Publication wiring auto-merges after CI/diff gates without a human/environment approval checkpoint required by publication policy. Consequence: This blocks publication-policy readiness, but does not show broken newsroom staging/source wiring.
- CF-05 P1 CONFIRMED: Declared Codex model name does not survive Spawnfile-to-Daimon lowering. Consequence: Production wakes can run with the Codex CLI default rather than the declared gpt-5.4-mini model.
- CF-06 P2 UNVERIFIED_OPERATIONAL_BOUNDARY: No production provisioning path was established for the direct-research-restriction profile/sandbox environment. Consequence: Operational enforcement remains unverified; this is classified as a provisioning-boundary uncertainty.
- CF-07 P2 CONFIRMED: Declared schedule jitter does not survive Spawnfile-to-Daimon lowering. Consequence: Scheduled wakes run at exact normalized times instead of the declared 900-second jitter.
- CF-08 UNKNOWN UNKNOWN_UNVERIFIED_BOUNDARY: Same-container credential filesystem isolation cannot be proven or disproven from the static source excerpts. Consequence: Credential boundary remains an explicit UNKNOWN pending deployment/container/mount evidence.
