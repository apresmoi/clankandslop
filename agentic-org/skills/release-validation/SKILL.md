name: release-validation
description: Gate a bounded edition handoff before its named-zone deadline.
---

Run deterministic validation and existing content validation only at the final boundary. Reject on schema, reference, ownership, terminal-state, or deadline failure. `RELEASE_HANDOFF` remains an internal handoff. Pressman alone may transform a finalized composition into one digest-keyed local artifact and one matching causal `staged` receipt. `published` is reserved for an actual publisher execution, which this organization does not declare. Never invoke a network publisher or Git push.
