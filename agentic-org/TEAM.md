# Clank & Slop organization

This is a portable, bounded Spawnfile organization. It does not start until `scripts/check-runtime.mjs` verifies each isolated agent home, host-provisioned CLI login, private root, broker, network policy, and Git policy. Spawnfile owns the public Git workspaces, private sensor volumes, shared edition-state volume, durable Moltnet storage, and secret-backed network bindings. Every agent declares its Daimon CLI engine directly: Grok for the scouts and reporters, Codex subscription CLI for the release desk.

AGY remains a future broker target, not a runtime engine in this portable Linux build. Host admission may confirm that the AGY subscription login exists, but its current host authentication cannot be portably staged into the Linux container. No manifest may claim otherwise or silently fall back to AGY.

The Spawnfiles deliberately omit a `policy` override. Daimon reports its workspace sandbox intent as degraded; Spawnfile's public default reports that adapter limitation without treating it as an authorization decision. `check-runtime.mjs` remains the fail-closed admission gate for actual homes, logins, private storage, broker, Moltnet, network, and Git policy.

The root owns one managed Moltnet server with durable SQLite state, bearer admission, private member-written rooms, and no human ingress. Agent, research-service, operator, and observe-only console identities reference distinct runtime secrets; no value is authored into a Spawnfile. The research sensor attaches directly to the cloud `research` room, which remains the single source of newsroom history.

Spawnfile 0.1.17 requires Daimon Grok and AGY agents to omit `execution.model`: Daimon owns their subscription authentication and model selection. Codex agents retain the supported OpenAI target with `auth.method: codex`. `check-runtime.mjs` still blocks launch until host-provisioned isolated CLI homes and login capabilities exist.

Daily lifecycle uses `Europe/Berlin` and never a fixed UTC offset. Reporters wake natively at 10:00 to read their own beat and pitch; Brass runs conference at 10:30 and selects the lineup from those pitches; Spike reviews at 14:00; Ledger settles the desk documents at 14:00; Caslon composes at 15:00; Pressman stages and pushes the edition branch at 16:00. Every checkpoint with a named agent owner is a native Spawnfile schedule that actually fires: a checkpoint described only in prose is a checkpoint that never runs. Reporters find their own stories — Brass picks which run and kills the rest, and commissions only what the day is missing. Research is a service, not a colleague: any reporter may request it and receives a committed pointer, never a payload. Every downstream activation is an explicit Moltnet message carrying edition and causal artifact references. Human kickoff, task orchestrators, hidden activation, and polling are prohibited.

Durable `edition-state` records are the only recovery authority. Prompts and chat history never reconstruct an edition. Raw research remains in sensor volumes or the private broker. Caslon deterministically composes assigned `PASS` artifacts only; Pressman alone writes one composition-digest-keyed local artifact, its causal `staged` receipt, and one pushed `edition/<date>` branch with its causal `pushed` receipt. No production `published` state exists: merging is a human decision and the organization declares no publisher that can make it.

The public paper’s established article schema, editorial voice, source rules, page blocks, visual grammar, formula authority, and per-owner boundaries are acceptance criteria. Private pipeline names, browser tooling, credentials, and private paths never enter articles, page copy, or public artifacts.

A mention is the literal token `@<agent-id>` — `@cogsworth`, `@world-scout`. Mentions are the only thing that wakes a peer: a bare name, a role word, or a capitalised label addresses nobody and the assignment is never delivered. Every handoff below that says "mentions" means this exact form.

Production turns use the declared newsroom MCP tools and `moltnet_send`; test-runtime cognition is never an acceptance surface. Chat is natural-language coordination, not JSON. JSON belongs in the durable tool artifacts. Every tool call carries the immutable inbound `event_key` or schedule occurrence so retries converge:

- Klaxon calls `mcp_newsroom_qualify_signal`, then sends a concise human-readable summary to `room:sensor` mentioning every returned selected desk. A private path is provenance only; the natural-language sensor handoff must itself contain the ranked claims, primary URLs, and verification gaps.
- Brass calls `mcp_newsroom_record_assignment` for at least five sourced stories, then sends each reporter a natural-language assignment in `room:assignment`. The lineup preserves the diversity floor and includes a dated forecast with named dissent.
- Reporters ground the Record, write in their established byline voice, call `mcp_newsroom_file_article`, and announce the filing in `room:filing` with the article id, revision, and evidence count. Revisions use a new event key and never overwrite a conflicting durable event.
- Spike reads every filed article and calls `mcp_newsroom_review_article`. `REVISION_REQUEST` mentions the owner with actionable notes; only `PASS` proceeds. Spike never rewrites reporter prose.
- Ledger calls `mcp_newsroom_file_desk` for `ledger.settlements` and `ledger.worlddesk`, using only formulas and inputs authorized by SYSTEMS.md.
- Caslon calls `mcp_newsroom_file_desk` for `caslon.chrome` and `caslon.weather`, then `mcp_newsroom_compose_edition` with exactly `front` and `tape` pages plus only maps actually used. Composition requires at least five articles, four desk files, matching PASS verdicts, two distinct papers, and the established 2–3 illustration rhythm. Caslon is the sole illustration authority: it bakes each edition's maps from the read-only ETOPO1 grid and selects glyphs from the permitted roll catalogue, both governed by `SYSTEMS.md`. Reporters describe what a story is about and never name a glyph, choose bounds, or place a block; no agent fetches or generates a 3D model.
- Ledger calls `mcp_newsroom_file_desk` for `ledger.settlements` and `ledger.worlddesk` at 14:00, using only formulas and inputs authorized by SYSTEMS.md. Composition cannot proceed without both.
- Pressman calls `mcp_newsroom_stage_release` only after Caslon’s receipt. It copies the full public source into its local staging volume, writes `content/editions/<date>/{articles,desk,pages,maps}`, runs the content validator and site build, and records the local receipt. It then calls `mcp_newsroom_push_edition`, which puts exactly that staged edition directory on one branch, `edition/<date>`, in the public repository and announces the branch and commit in `room:release`. The push is fast-forward, one ref, derived from the edition date: it never reaches `main`, never force-pushes, never deletes a remote ref, and never merges. A deploy key can push Git and cannot open a pull request, so a person opens the PR and decides what ships. Pressman calls no hosted publisher and holds no API credential.

The visible handoff is `research sensor → Klaxon selected mentions → Brass assignments → reporter filings → Spike verdicts → Ledger settlements → Caslon composition → Pressman staging → Pressman edition branch → human pull request`. Missing sources, failed validation, a failed build, fewer than five articles, absent desk/page files, or non-PASS prose stops the edition.

The compiler-owned edition state contains `sensor-ledger`, `candidates`, `evidence`, `pinpoint`, `dossiers`, `compose`, `decisions`, and `receipts`. Raw sensor corpus stays in the four isolated corpus volumes. Public messages name only concise summaries and relative private artifact references plus digests.
