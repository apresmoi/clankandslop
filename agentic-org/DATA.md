# Ownership and paths

| Owner | Private writable paths | Public writable paths |
| --- | --- | --- |
| sensors | sensor-ledger, candidates, evidence, pinpoint, dossiers | none |
| reporters | dossiers and assigned article artifacts | assigned article artifacts only |
| Ledger | decisions, receipts | ledger-owned generated records |
| Caslon | compose | page composition only |
| Morgue | receipts | archive receipts only |
| Pressman | receipts | release receipt only |

Spike and Caslon may reject or request revision; they never write reporter-owned prose. Deterministic gates validate and reject only.
