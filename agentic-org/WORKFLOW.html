Readiness gaps that affect this flow
  • 03 / Freshness: the agents still mount the September 6 corpus. Sensor commits do not automatically replace the pinned bundle; the daily private merge is scheduled at 16:08 with up to 10 minutes of delay.
  • 04 / Wake delivery: rolling notices reach the research room without @Klaxon. A message existing in history does not prove a useful agent wake.
  • 06 / Assignment room: TEAM says assignment; Brass’s schedule prompt directs announcements to conference. Both rooms permit mentions, but the written handoff needs one contract.
  • 07 / Agent guidance: the deployed research document describes a responder that is not built. Branch documentation has been corrected; deployment and a real Daimon acceptance test remain required.
  • 07 / Internet restriction: a prompt rule is insufficient. The live launcher uses unrestricted sandbox access, and historical reporter sessions contain native web searches. Network enforcement still needs an isolated failing test.
  • 08–13 / Edition correctness: September 6 reached only three PASS articles and no desk documents. Article filing accepted shapes that later failed the site validator; HOLD recovery, desk inputs and failed-turn usage accounting also remain open.
  • All agents / Model drift: the declarations name gpt-5.4-mini, while live Codex homes and a real reporter turn use gpt-5.5. Klaxon’s older Grok description also disagrees with its deployed Codex engine.
  • 12 / Art availability: some briefs promise map baking that the runtime cannot perform. The supported runtime path is the committed asset catalogue.
  • 15–16 / Release: prose says human approval; the checked-in edition workflow automerges after CI. The complete branch-to-deployment hop has not been accepted as part of an autonomous edition.
Shared tools, rooms and research limits

Agents use moltnet_read and moltnet_send for coordination, and their named mcp_newsroom_* tools for durable edition state. A literal @agent-id requests a peer turn; ordinary chatter does not. Read the edition index and only the referenced record. Personal memory supports continuity; it does not replace the edition ledger.

Conference holds pitches and editorial debate; assignment holds commissions; filing carries article and review handoffs; sensor carries qualified leads; research carries service requests and answers; release coordinates composition and staging. Research requests are the JSON service exception to ordinary natural-language conversation.

The deployed responder admits the six reporters and Brass: one question per request, two requests per requester and twelve total per edition by default, including failed attempts. One durable queue shares browser locks with rolling research. Replies contain findings and URLs, or an explicit not-found/refused status. A sensor’s citation is attributed research, not proof that a reporter personally opened the source.

The production research room still depends on Hetzner. Cloudflare relays the newsroom to an observer; it does not host an independent newsroom API or database. The successful isolated test used its own Moltnet server on the 4090.
