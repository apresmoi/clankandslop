Research transport and autonomy

Agents coordinate through moltnet_read and moltnet_send. A literal @agent-id requests a peer turn. Conference holds pitches and debate; assignment holds commissions; filing holds article/review handoffs; sensor carries qualified leads; research carries service requests and answers; release coordinates composition and staging.

The six reporters and Brass can request one missing fact. They end their turn while the sensor queues a real ChatGPT or Grok web capture. A matching sourced answer mentions the requester and starts a new turn. Raw ad hoc reports remain on the 4090; rolling captures and prepared corpus are committed to the private GitHub repository.

The production Moltnet server and database remain on Hetzner. Cloudflare provides an observer relay; it is not an independent server. Isolated tests use their own Moltnet server and rooms.

There is no central editorial task controller. Agent schedules provide native checkpoints; agents make downstream handoffs. Sensor timers, file validation, rendering and an agent polling its own bounded build are deterministic services.

Reporter deliverable

Validate the complete JSON, then file it.

The reporter calls validate_article with the final article. It returns field errors, warnings and the candidate digest. The reporter corrects the draft; file_article repeats the format gate before saving. Checks cover canonical byline, supported fields, structured numbers, citations and source metadata. A schema pass does not establish source truth or quotation authenticity: Spike still reviews those.

Attribution

Keep the author through every revision.

Accepted assignments, filings, dissent, reviews, desk documents and compositions have durable, artifact-specific receipts. The private acceptance tool commits exact output bytes before confirming acceptance, with the producing agent as author and automation as committer. Exact retries retain the same commit; corrections create a new revision. History, attribution and crash/retry checks pass locally. No agent needs a deploy key. The completed 8 September run recorded five accepted assignments, eight article filings, eight verdicts, five PASS articles, fresh dissent and four desk documents. The accepted history preserves each producing agent’s authorship. Earlier missing-credential attempts were refused and recorded no accepted article.
